# AI-Face-Recognition
Face-Recognition-System - yolo v8
📌 AI Face Recognition / Face ID System
📝 Overview![Uploading 2.png…]()


This project is an AI-based Face Recognition (Face ID) system designed to detect, recognize, and verify human faces using computer vision and machine learning techniques.
The system can be used for authentication, attendance, and security applications.

🧠 System Capabilities

Face detection from images or live camera

Face recognition and identity matching

Face ID verification (one-to-one matching)

Real-time processing

🛠️ Technologies Used

Programming Language: Python

Libraries: OpenCV, NumPy, TensorFlow / Keras (or face_recognition)

Algorithms:

Haar Cascades / CNN for face detection

Face embeddings for recognition


⚙️ How It Works

Capture face images

Detect face regions

Extract facial features (embeddings)

Compare faces using similarity metrics

Identify or verify the user
